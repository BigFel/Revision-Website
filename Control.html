Control Structures

Hope this helps you understand the different approaches to software development.

Sequence

Sequence is the simplest control structure. It ensures that every process is performed in a strict, top to bottom order.

The Rule: Each step must be completed before the next one begins.

Example: In a "Get Dressed" algorithm, you must put on your socks before your shoes. If the sequence is wrong, the program fails.

Selection

Selection allows a program to choose between different paths based on a condition (a "Boolean" True/False check).

Purpose: The control structure that allows decisions to be made between different alternativepaths.

Binary Selection (IF-THEN-ELSE): Choosing between exactly two alternatives.

  • Example: Age >= 18 THEN "Can Vote" ELSE "Cannot Vote".

Multiway Selection (CaseWhere): Choosing from many different paths.

  • Example: Assigning grades (A, B, C, D, or F) based on a student's score.

Iteration

Iteration is the repetition of a sequence of steps. This is what makes computers powerful, they can repeat tasks at incredible speeds.

  • Pre-Test Loop (WHILE): The condition is checked at the start. If the condition is false, the loop might never run (0 times).
  • Post-Test Loop (REPEAT-UNTIL): The condition is checked at the end. The loop is guaranteed to run at least once.
  • Counting Loop (FOR): Used when you know exactly how many times you want the loop to repeat.
