Data Types

Hope this helps you understand the different data types used in programming.

Text-Based Data Types

  • Character: A single letter, number, space, or symbol (e.g., 'A', '7', or '$').

  • String: A sequence of characters (e.g., "Hello, World!").

Number-Based Data Types

  • Integer: A whole number (e.g., 5, -10, 0).

  • Float: A number with a decimal point (e.g., 3.14, -2.5).

Logical Data Types

  • Boolean: A data type that can only hold one of two possible values: True or False (sometimes represented as Yes/No or 1/0). Used for logic checks, such as if a user is logged in or if a game is over.
