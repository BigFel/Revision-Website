Python Data Storage and Memory

Hope this helps you understand how Python handles data storage and memory management.

Variables

Variables are containers for a single piece of data. They are the simplest form of program memory.

  • Purpose: To store one item that might change while the program is running.
  • Examples: A player's current score, a user's password, or a temperature reading.
  • Creation: Can be set automatically by the code or manually entered by the user.

Arrays

Arrays (often called Lists in Python) are used to store multiple items of the same type in a single container.

  • Purpose: To keep related items together so they can be easily searched or sorted.
  • Examples: A list of Simpson characters, a set of high scores, or all the year groups in a school.

Records

A Record allows you to store a collection of related items that have different data types.

  • Purpose: To group different details about a single "entity" (like a person or a product).
  • Example (student record): A single record for a student might contain their First Name (Text), Age (Integer), and Date of Birth (Date).
  • Language Differences:
    • Python: Coded using Class Structures.
    • C++: Coded using Structs.
    • Databases/Java/Pascal: Coded as Records.

Files

Files are permanent containers used to store multiple records long-term, even after the program is turned off.

  • Purpose: To provide "Persistent Storage" for large amounts of data.
  • Key Features: Files often store data as CSV (Comma Separated Values) and can be imported from or exported to SQL Databases.
